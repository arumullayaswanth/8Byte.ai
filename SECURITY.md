# Security Policy

## Reporting a vulnerability

If you find a security issue in this project, please open a private security
advisory through the repo's Security tab rather than a public issue, or email
the maintainer directly. I'll look into it and respond as soon as I can.

## What's in place

- Dependabot alerts and version update PRs
- CodeQL code scanning on every push and pull request
- Secret scanning
- Dependency scanning (npm audit) and container/IaC scanning in CI
